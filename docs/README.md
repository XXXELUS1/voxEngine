# Документация voxEngine — индекс

Проза здесь на русском, идентификаторы, пути и команды — на английском. Точка входа для Claude Code —
[`../CLAUDE.md`](../CLAUDE.md); точка входа для владельца — [`../README.md`](../README.md).

## Контракты (источник истины) — `spec/`

| Файл | О чём | Кто на него опирается |
|---|---|---|
| [`spec/vxm-format.md`](spec/vxm-format.md) | Бинарный формат `.vxm`, таблица материалов, биты состояния, оси, экспорт в `.vox` | `tools/voxgen/voxgen/io_vxm.py`, `src/voxbody/src/voxel_model.cpp` |
| [`spec/voxbody-api.md`](spec/voxbody-api.md) | Классы, методы и сигналы GDExtension; контракт мешера и шейдера; тинт состояний | `src/voxbody/`, `godot/scripts/`, `godot/addons/voxbody/voxel.gdshader` |
| [`spec/voxgen-cli.md`](spec/voxgen-cli.md) | Команды CLI, формат спека, минимум библиотеки, проверки, тесты | `tools/voxgen/` |

Порядок: сначала правим спеку, потом код. Код не противоречит спеке; где спека молчит — решение
документируется в шапке файла или в ADR.

## Дизайн — `design/`

- [`design/barberians.md`](design/barberians.md) — диздок владельца. Для движка важны разделы «Опоры и
  правила дизайна», «Повреждения», «Инструменты», «Визуал и звук», «Техника», «Этапы». Не правим без просьбы.

## Архитектурные решения — `adr/`

| № | Решение |
|---|---|
| [0001](adr/0001-godot-4.7.md) | Godot 4.7 как движок |
| [0002](adr/0002-own-voxel-core.md) | Собственное воксельное ядро вместо `godot_voxel` |
| [0003](adr/0003-cpp-godot-cpp.md) | C++ через godot-cpp 10 (не Rust, не C#) |
| [0004](adr/0004-two-layer-pipeline.md) | Двухслойный пайплайн: Python-генератор + текстовые спеки, `.vxm` как контракт, превью как глаза агента |
| [0005](adr/0005-deterministic-ops.md) | Детерминированные целочисленные операции над вокселями как основа сетевой модели |
| [0006](adr/0006-dense-arrays.md) | Плотные массивы на часть вместо двухуровневой сетки (пока не упрёмся) |

Новый ADR: следующий номер, тот же шаблон (Статус / Дата / Контекст / Решение / Последствия), строка в
этой таблице. ADR не переписываются задним числом: отменённое решение получает статус «заменено ADR-NNNN».
