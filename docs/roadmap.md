# Роадмап движка voxEngine

Переложение раздела «Этапы» диздока (`design/barberians.md`) на движок тел и повреждений. Каждый пункт —
одна строка с компонентом в квадратных скобках: `[voxgen]` генератор, `[voxbody]` C++-расширение,
`[godot]` лаборатория и GDScript, `[docs]` документация, `[infra]` скрипты/CI/хук. Пункты игры (цирюльня,
экономика, NPC-система, звук) здесь не ведутся — только то, на чём они будут стоять.

Статус отмечается чекбоксами; текущий этап продублирован в `CLAUDE.md` → «Текущий этап».

## Этап 1 — Прототип ядра: весело ли само по себе

Из диздока, «1. Прототип ядра». Критерий этапа: владелец и один кент пять минут режут голову и смеются.

- [ ] Воксельная голова со слоями в Godot: срез показывает кожу → жир → мышцу → кость, кость не режется бритвой (только ложкой/клещами) `[voxbody]` `[godot]`
- [ ] Бритва мышью: скорость = глубина, тонкий ровный срез на медленном движении, «пахота» на быстром; звук-заглушка по событию `op_applied` `[godot]`
- [ ] Клещи: захват зуба под курсором, удержание + рывок → `MAT_TOOTH`-компонент отделяется как отдельный объект (детач по материалу/якорю) `[voxbody]` `[godot]`
- [ ] Пауза перед последствием: рана проступает через ~0.5 с (кровь появляется по таймеру, не мгновенно) `[godot]`
- [ ] Клиент дёргается: процедурный «flinch» головы по силе/материалу операции (сдвиг, поворот, возврат) `[godot]`
- [ ] Клиент бьёт в ответ: простая машина состояний (терпит → дёргается → отмахивается) с порогами по сумме повреждений `[godot]`
- [ ] Схватить, утащить, бросить: взятие RigidBody курсором (кубики вместо людей), перенос, бросок с импульсом `[godot]`
- [ ] Сравнить 3 / 5 / 8 мм в лаборатории при настоящем свете; решение владельца → стиль-гайд + ADR `[voxgen]` `[docs]`
- [ ] Пропорции: вариант `caricature` в `_human_head.py`, сравнение с `default`, решение владельца → стиль-гайд `[voxgen]` `[docs]`
- [ ] Детерминизм: тест «одно событие на двух копиях объёма → одинаковые поля», квантование аргументов в GDScript-слое `[voxbody]` `[godot]`
- [ ] Производительность: перестройка 48³ ≤ 5 мс в release измерена и записана; обломки не роняют FPS `[voxbody]`
- [ ] Сохранить/загрузить повреждённую голову (`VoxelModel.save_to_file`) из лаборатории — для баг-репортов владельца `[godot]`

## Этап 2 — Тело, время, сеть

- [ ] Привязка частей к скелету: `VoxelPart` под `BoneAttachment3D`, поле `bone` из `.vxm`, универсальный скелет (Mixamo-совместимый) `[voxbody]` `[godot]`
- [ ] Части тела в voxgen: кисти 6 мм, туловище 15 мм, челюсть/уши/нос как отдельные части на своих костях `[voxgen]`
- [ ] Коллизии по капсулам на костях (активный рэгдолл, Jolt), воксели только для визуала и повреждений `[godot]`
- [ ] Рост волос: операция удлинения столбиков `MAT_HAIR` с seed, вызывается по игровому времени `[voxbody]`
- [ ] Мокрые волосы: бит `WET` + шейдер (темнее) + опадание (наклон столбиков) `[voxbody]` `[godot]`
- [ ] Синяк во времени: уровень 1 → 2 → 3 по таймеру, заживление в обратную сторону, шрам как остаточный оттенок (бит 7 состояния) `[voxbody]` `[docs]`
- [ ] Ожог во времени и огонь по волосам: распространение `burn` по соседним столбикам `[voxbody]` `[godot]`
- [ ] Лужи крови: частицы/декали от событий `op_applied` с `STATE_BLOOD`, не воксели `[godot]`
- [ ] Одежда как тонкая оболочка (`MAT_CLOTH`, `MAT_LEATHER`) поверх тела, пятна — состояние `[voxgen]` `[voxbody]`
- [ ] Мимика на костях (брови, веки, челюсть) + перекраска вокселей (покраснел/побледнел) `[godot]` `[voxbody]`
- [ ] Сеть: события операций с порядковым номером, снапшот `.vxm` при входе, 2–4 игрока в лаборатории `[godot]` `[voxbody]`
- [ ] Импорт правок владельца из MagicaVoxel как штатный путь (спек-обёртка над `.vox`) с тестом `[voxgen]` `[docs]`
- [ ] Библиотека частей: носы, уши, челюсти, причёски как параметры/модули спека — конструктор типажей `[voxgen]`
