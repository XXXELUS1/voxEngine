# Спецификации этапа «Движок v2»

Направление, зафиксированное с владельцем (16.10.2026):

- Движок и инструмент для моделей сейчас важнее сцен игры.
- Источники моделей: текстовый запрос Клоду (спек на Python), картинка-референс, меш из Tripo/Blender, STL.
  Лепка с нуля в MagicaVoxel не нужна, MagicaVoxel остаётся для правок.
- Стили рендера сравниваем на стенде: кубики, скруглённые кубики, гладкая поверхность, пластилин, тун,
  рейкаст по 3D-текстуре. Шарики отброшены.
- Скелет: гуманоидный профиль Godot (`SkeletonProfileHumanoid`) с ретаргетом Mixamo; шаблоны четвероногого
  и птицы (гусь). Мягкий скиннинг по суставам, без жёстких «лего»-частей. Рэгдолл на капсулах по костям.
- Слои повреждений на всём теле.
- Сначала один эталонный человек до идеала визуала, потом параметры (уши, зубы, вес, возраст).
- Красивые рендеры через Blender (bpy 4.5 LTS в venv), веб-просмотрщик по ссылке для телефона.

Порядок: эталонный человек со скелетом → стенд стилей → импортёры → авториг → генератор жителей.

| Файл | О чём |
|---|---|
| `vxm-format-v2.md` | Расширение формата: скелет, веса, пространство части, физика костей |
| `skinned-body.md` | Рантайм: `VoxelSkinnedBody`, чанки, скиннинг, удары по скелетированному телу |
| `styles.md` | Стенд стилей: мешеры, шейдеры, Blender-рендеры, веб-просмотрщик |
| `human-builder.md` | Эталонный человек: скелет по построению, мясо, слои, веса, параметры |
| `importers.md` | GLB/OBJ/STL/.vox → .vxm: вокселизация, цвет из текстур, автослои, веса |
| `autorig.md` | Авториг нерижённых моделей: скелетизация, шаблоны, веса |
