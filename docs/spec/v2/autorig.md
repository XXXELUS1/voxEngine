# Авториг нерижённых моделей

`voxgen autorig <model.vxm> --profile humanoid|quadruped|bird --out <model.vxm> [--preview]`
(`voxgen/autorig.py`). Вход: часть `space: "rest"` без весов (или `world`), модель стоит на полу, Y вверх,
−Z вперёд; для гуманоида — T- или A-поза.

## Идея

Не общая скелетизация, а **подгонка шаблона**: у нас всегда известен тип существа. Шаблон задаёт порядок
суставов, их пропорции и какие «оконечности» искать.

## Шаги (гуманоид)

1. Solid-маска → наибольшая связная компонента. Центроид `c`, рост `H` (bbox по Y).
2. Оконечности: геодезические максимумы — BFS от `c` по solid, берём 5 локальных максимумов расстояния с
   подавлением соседей (радиус `0.15·H`): голова (самый высокий), две стопы (самые низкие), две кисти (по X).
   Для A-позы кисти — по максимуму `|x|` среди оставшихся.
3. Пути: геодезические кратчайшие пути от каждой оконечности к `c` (BFS с восстановлением). Путь кисти →
   сустав плеча там, где путь входит в торс (локальная толщина `t` резко растёт); локоть — на середине между
   кистью и плечом (± коррекция по минимуму толщины). Ноги: таз/колено/лодыжка — аналогично, колено по минимуму
   толщины в средней трети. Позвоночник: от таза к голове вдоль пути головы: `Hips`, `Spine`, `Chest`,
   `UpperChest`, `Neck`, `Head` на долях 0 / 0.2 / 0.45 / 0.65 / 0.85 / 1.0 длины пути до основания черепа
   (основание черепа — где толщина снова растёт после шеи).
4. Скелет в T-позе из найденных суставов, `rest_rot` — из направлений сегментов (кватернион «из Y в
   направление»), родительские трансформы по цепочке. Имена — профиль Godot.
5. Веса — `assign_weights` из `human-builder.md` (геодезически, `blend_width` по разрешению).
6. Физика костей — как в `human-builder.md`.
7. Отчёт: найденные суставы и уверенность (расстояние найденных пропорций от шаблонных); превью с
   наложенным скелетом и картой весов (`build/previews/<name>_rig.png`).

## Четвероногое

Оконечности: 4 стопы (нижние), голова (самая передняя/верхняя по −Z/Y), хвост (самая задняя). Цепочка
`Hips → Spine → Chest → Neck → Head`, ноги `*UpperLeg → *LowerLeg → *Foot` (перед/зад), хвост 2–3 кости.
Имена костей — свои (профиль `quadruped`), ретаргет не стандартный.

## Птица (гусь)

Оконечности: 2 стопы, голова (по длинной шее: путь с наибольшим числом тонких вокселей), хвост; крылья —
сложенные, как два сегмента по бокам (опционально). Шея — 4 кости.

## Проверка

`godot/scenes/anim_test.tscn` крутит кости синусом; тест: после `autorig` у `human_ref` (с удалённым
скелетом) найденные суставы отличаются от исходных не больше чем на 3 см, веса совпадают с исходными в ≥ 95 % вокселей.
