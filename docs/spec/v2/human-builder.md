# Эталонный человек: скелет по построению, мясо, слои, веса, параметры

`tools/voxgen/voxgen/human.py` + спек `tools/voxgen/specs/human_ref.py` (`build() -> Model`).
Цель: один человек «до идеала», затем параметры → жители.

## Параметры (`HumanParams`, dataclass, все с дефолтами, единицы — метры/доли)

`height=1.75, build=0.5 (0 худой … 1 тучный), shoulder_width=0.46, hip_width=0.36, head_size=1.0,
neck_len=1.0, arm_len=1.0, leg_len=1.0, hand_size=1.0, belly=0.0..1, age=0..1 (сутулость, морщины-цвет),
sex="m"|"f"`, лицо: `jaw_width, chin_len, nose_len, nose_width, ear_size, ear_stickout, eye_size, brow,
lip_fullness, cheek_fullness, teeth_count (32 по умолчанию, недостающие — случайные пропуски), bald=0..1,
hair_len_vox, beard=0..1`, цвет: `skin_tone (индекс пресета), hair_color, eye_color`, `seed`.
Все параметры читаются из dict (`HumanParams.from_dict`), чтобы спек жителя был просто словарём.

## Скелет (`voxgen/rig.py`)

`humanoid_skeleton(params) -> Skeleton`: позиции суставов в T-позе из пропорций (роста и множителей),
имена — профиль Godot (см. `vxm-format-v2.md`). `Skeleton` знает `global_rest(bone)`, `local_rest(bone)`,
`segment(bone) -> (p0, p1)` и пишется в header.

## Мясо (SDF, метры)

Для каждой кости — капсула/эллипсоидный «сегмент мышцы» с радиусами из параметров (плечо шире у плеча, уже у
локтя; бедро; голень; стопа — скруглённый бокс; кисть — ладонь-бокс + пять пальцев-капсул по 3 фаланги,
минимально при 10 мм: пальцы ≥ 2 вокселя толщиной). Торс — объединение эллипсоидов (грудь, живот по `belly`,
таз), шея — капсула. Голова — из `_human_head.py` (параметризовать его теми же лицевыми параметрами) как
отдельная часть 5 мм. Сглаженное объединение (`smooth_union`, k ≈ 0.02 м) на суставах, чтобы не было
перетяжек. Лёгкий value-noise по поверхности (амплитуда 1 воксель) для органики, симметрия `mirror_x`.

## Слои (всё тело)

- `skin` 1 воксель; `fat` 1–3 вокселя по `build` (толще на животе/ягодицах/щеках); `muscle` — остальное до кости;
  `bone` — капсулы костей: радиус 0.012–0.035 (бедро/плечо толще), таз и грудная клетка — эллипсоиды
  (рёбра не моделируем), череп — из головы; `vessel` — капсулы 1 воксель: шея (сонные), внутренняя сторона
  бедра и плеча, запястья; `cartilage` — нос, уши; `tooth`, `eye` — в голове; `nail` — 1 воксель на кончиках пальцев.
- Волосы: скальп (как в голове), брови, щетина/борода по `beard`, предплечья/грудь — опционально редкие столбики 1 воксель.

## Веса (`voxgen/rig.py: assign_weights(part, skeleton)`)

Геодезически, а не евклидово:
1. Для каждой кости отмечаем «семя» — воксели в радиусе `r_bone` от сегмента кости (внутри solid).
2. Многоисточниковая BFS (6-связность) по solid-вокселям части от всех семян одновременно, с меткой кости;
   получаем `bone0` и расстояние `d0`. Вторая BFS с запретом на кость `bone0` — не нужна: вместо этого
   для каждого вокселя берём расстояние до семян соседних костей в графе скелета (родитель/дети `bone0`),
   считая BFS от каждой кости отдельно (≤ 25 BFS на 400k вокселей — секунды в numpy).
3. Вес: `t = clamp((d1 − d0) / blend_width, −1, 1)`, `w0 = 255·(0.5 + 0.5·t)` → плавный переход шириной
   `blend_width` (≈ 3 вокселя при 10 мм, 6 при 5 мм) только в зоне сустава. Внутри сегмента `w0 = 255`.
4. Жёсткие исключения: `bone`, `tooth` — `w0 = 255` к своей кости (кость не тянется); `Jaw` — отдельная кость
   нижней челюсти, веса по вокселям ниже линии рта (`landmarks.mouth`).
5. Кости без мяса (`Root`, `LeftEye`) получают пустые наборы — допустимо.

## Физика костей

`physics.radius` = 90-й перцентиль расстояния «вокселей кости» от оси сегмента; `height` = длина + радиус.

## Проверки (дополнение к `checks.py`)

`weights_cover` (все solid-воксели имеют bone0 ≠ 255), `weights_smooth` (нет скачка w0 > 128 между 6-соседями
вне зоны суставов), `bone_inside` (кость не выходит на поверхность, кроме зубов), `pose_tpose` (кисти на
высоте плеч ± 5 см), `symmetry_x` для всего тела.

## Выходы
