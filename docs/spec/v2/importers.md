# Импортёры: GLB / OBJ / STL / .vox → .vxm

`voxgen import-mesh <file.glb|.gltf|.obj|.stl> --voxel-size 0.01 --out <name>.vxm [--part-name body]
[--space rest|world] [--autolayer human|solid|none] [--fill|--no-fill] [--scale S | --height H]
[--up y|z] [--forward -z|+y] [--center feet|origin] [--bones auto|none] [--preview]`

`voxgen import-vox <file.vox> [--spec-json …] [--autolayer …] --out <name>.vxm` (v1 + автослои).

## Загрузка мешей

Зависимость `trimesh` (чистый Python + numpy) для GLB/glTF/OBJ/STL, текстуры через PIL. Единицы: предполагаем
метры; `--height` масштабирует модель до роста (по Y после `--up`). Ось вверх/вперёд приводим к Godot (Y вверх, −Z вперёд).

## Вокселизация

1. Поверхность: для каждого треугольника — равномерная выборка точек с шагом `voxel_size/2` (барицентрически),
   отметка вокселей; цвет точки — из текстуры по UV (nearest/bilinear) или базового цвета материала, или
   вершинных цветов; для вокселя — средний цвет его точек → ближайший цвет палитры (палитра строится
   квантованием k-means/median-cut всех цветов поверхности до ≤ 200 цветов + служебные цвета слоёв).
2. Заполнение (`--fill`, по умолчанию да): «воздух» заливается от границ бокса (6-связность) → всё
   незалитое = внутри → solid. Незамкнутые меши: заливка просачивается внутрь — предупреждение в отчёте с
   числом «дырявых» вокселей; опция `--fill-close N` сначала расширяет поверхность на N вокселей.
3. Материал: поверхность → по `--autolayer`:
   - `none`: всё `MAT_GENERIC`, цвет как есть (пропсы);
   - `solid`: по имени материала меша (`wood*`, `metal*`, `stone*`, `cloth*` …) → id пропса, иначе generic;
   - `human`: `autolayer(...)` (ниже).

## Автослои (`voxgen/layers.py: autolayer(part, profile="human")`)

Вход: solid-маска (+ цвет поверхности). Шаги:
- Глубина `d` от поверхности: многоисточниковая BFS от поверхностных solid-вокселей (6-связность), в вокселях.
- Локальная толщина `t`: расстояние до поверхности, измеренное через центр: `t = 2·max_d` по компоненте
  «ядра» (приближённо: максимум `d` в окне 7³ вокруг вокселя).
- Пороги в метрах → вокселях по `voxel_size`: skin `≤ 0.005`, fat `≤ skin + 0.004 + 0.02·build`, muscle до
  кости; `bone` там, где `d ≥ fat_depth + muscle_min` **и** `t ≥ 0.03` (тонкие части — пальцы, уши — без кости);
  `cartilage` — уши/нос, только если переданы landmarks/маски; `vessel` — не ставим (нечего угадывать).
- Цвет: поверхность сохраняет импортированный цвет (кожа как в текстуре); внутренние слои — цвета материалов из
  стандартной палитры тела.
- Волосы: если поверхностные воксели по цвету близки к «цвету волос» (параметр `--hair-color` или авто по
  тёмным вокселям на верхней трети головы), они помечаются `MAT_HAIR` и выращиваются столбиками `--hair-len`.

## Веса из рижённого GLB (`--bones auto`)

Если в GLB есть skin (joints/weights на вершинах): имена костей → профиль Godot через таблицу синонимов
(Mixamo `mixamorig:LeftArm` → `LeftUpperArm`, `LeftForeArm` → `LeftLowerArm` …; Tripo-риг — те же имена Mixamo
или свои, таблица расширяема в `rig_names.py`). Скелет пишется в header (rest из bind-поз). Веса вокселей:
поверхностный воксель берёт две главные кости ближайшей точки выборки; внутренние — BFS-распространением от
поверхности (ближайший поверхностный воксель по геодезике). Если в GLB скелета нет и `--bones auto` —
вызываем авториг (`autorig.md`).

## Отчёт импорта

`build/reports/<name>.json` дополняется: число треугольников, незамкнутость, доля залитых вокселей, размер
палитры, распределение материалов, предупреждения. Превью как у всех моделей.
