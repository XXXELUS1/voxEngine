# Формат `.vxm` (VoxModel) — контракт между voxgen (Python) и voxbody (C++)

Один файл = одна модель (персонаж или предмет) = набор **частей** (parts).
Часть — плотный блок вокселей, привязанный к кости скелета (или ни к чему для пропсов).

## Бинарная раскладка

```
offset  size        содержимое
0       4           magic: ASCII "VXM1"
4       4           header_len: uint32 little-endian
8       header_len  header: JSON в UTF-8 (без BOM)
...                 затем для каждой части по порядку, для каждого поля из part.fields по порядку:
                    nx*ny*nz байт сырых данных, индекс = x + nx*(y + ny*z)   (x меняется быстрее всех)
```

Сжатия нет. Файлы генерируются, в git не коммитятся.

## Header JSON

```json
{
  "format": 1,
  "name": "head_test",
  "voxel_size": 0.005,
  "palette": [[0,0,0], [224,180,150], ...],
  "materials": {"1": "skin", "2": "fat", "32": "wood"},
  "parts": [
    {
      "name": "head",
      "bone": "head",
      "voxel_size": 0.005,
      "origin": [-0.12, -0.04, -0.13],
      "dims": [48, 56, 52],
      "fields": ["material", "color", "state", "sdf"]
    }
  ],
  "meta": {"generator": "voxgen 0.1.0", "spec": "tools/voxgen/specs/head_test.py", "variant": "default"}
}
```

- `palette`: до 256 цветов `[r,g,b]` 0..255, sRGB. Индекс 0 зарезервирован (воздух), пусть будет чёрный.
- `materials`: справочник id → имя, только для удобства чтения. Истина — таблица ниже.
- `part.voxel_size`: метры на воксель этой части (у головы 0.005, у туловища 0.015). Если отсутствует, берётся верхний `voxel_size`.
- `part.origin`: позиция угла вокселя (0,0,0) в **локальном пространстве кости** (метры). Центр вокселя (x,y,z) находится в `origin + (x+0.5, y+0.5, z+0.5) * voxel_size`.
- `part.fields`: какие массивы записаны и в каком порядке. Обязательно `material`. `color` и `state` опциональны (при отсутствии: color = 0, state = 0); `sdf` — опциональное поле расстояний (ниже). Загрузчик обязан игнорировать неизвестные поля, пропуская nx*ny*nz байт (voxgen хранит их как сырые байты и пишет обратно).

| поле | тип | обязательно | что хранит |
|---|---|---|---|
| `material` | uint8 | да | материал (таблица ниже), 0 = воздух |
| `color` | uint8 | нет | индекс палитры |
| `state` | uint8 | нет | биты повреждений |
| `sdf` | int8 | нет | знаковое расстояние до поверхности в 1/16 вокселя, отрицательное внутри |
- Оси: Godot (Y вверх, −Z вперёд, правая система). Персонаж смотрит в −Z, X вправо от зрителя.

## Поле `material` (uint8)

Из чего воксель. 0 = воздух. Диапазон 1..31 — тело, 32..62 — предметы, 63 — generic.

| id | имя       | свойства |
|----|-----------|----------|
| 0  | air       | пусто |
| 1  | skin      | кровоточит при срезе, синяки ставятся только на ней |
| 2  | fat       | кровоточит |
| 3  | muscle    | кровоточит |
| 4  | bone      | твёрдая |
| 5  | tooth     | твёрдая, отдельный объект при отвале |
| 6  | cartilage | уши, нос |
| 7  | vessel    | кровоточит толчками (логика игры, не движка) |
| 8  | hair      | столбики над кожей; стрижётся `trim_hair_capsule`, сгорает при burn ≥ 2 |
| 9  | eye       | |
| 10 | nail      | |
| 32 | wood      | |
| 33 | metal     | |
| 34 | stone     | |
| 35 | cloth     | |
| 36 | leather   | |
| 37 | glass     | |
| 38 | ceramic   | |
| 39 | liquid    | |
| 40 | plant     | |
| 63 | generic   | |

Перечисление дублируется в `src/voxbody/src/voxel_volume.h` (enum `Material`) и `tools/voxgen/voxgen/materials.py`. Менять — в обоих местах.

## Поле `color` (uint8)

Индекс в `palette`. Рендер берёт базовый цвет отсюда, а не из материала: один материал может быть разных оттенков (кожа загорелая, кожа бледная).

## Поле `state` (uint8) — повреждения

| биты | маска | значение |
|------|-------|----------|
| 0–1  | 0x03  | уровень синяка 0..3: нет → красный → фиолетовый → жёлто-зелёный |
| 2–3  | 0x0C  | уровень ожога 0..3: нет → покраснение → волдырь → обугливание |
| 4    | 0x10  | CUT: свежесрезанная поверхность (рана) |
| 5    | 0x20  | BLOOD: кровь на поверхности |
| 6    | 0x40  | WET: мокрый (вода, пена) |
| 7    | 0x80  | зарезервирован |

Синяк и ожог меняют **оттенок** вокселя, не удаляют его. CUT/BLOOD выставляются движком автоматически на соседях удалённых вокселей (`carve_*`).

## Поле `sdf` (int8, опционально) — знаковое расстояние

Откуда берётся гладкая поверхность: воксели на 5 мм — ступеньки, и сглаживание бинарной сетки их не
убирает (щёки «гофрой»). Поэтому часть, которая была вылеплена гладкой SDF-формой (`voxgen.sculpthead`),
хранит само расстояние, а мешер гладкого вида строит точный ноль поля (Hermite surface nets:
точка пересечения на каждом ребре между соседними центрами вокселей — линейная интерполяция двух
значений, нормаль — градиент поля), без сглаживающих проходов.

- Значение на **центр вокселя**: `sdf = clamp(round(d / voxel_size * 16), -127, 127)`, где `d` —
  расстояние в метрах до поверхности части, **отрицательное внутри** тела, положительное в воздухе.
  Диапазон ±127/16 = ±7.9 вокселя, дальше поле насыщается (мешер его там не читает).
- **Согласовано с `material`**: воксель с `material != 0` имеет `sdf ≤ −1`, воздух — `sdf ≥ 0`, то есть
  `(sdf < 0) == (material != 0)` всегда; при квантовании ноль-пересечение сдвигается не более чем на 1/16 вокселя.
- Источник: точная SDF спека (`sculpthead` пишет свою `form_field`, вырезы — карман волос, глазницы —
  врезаны как `max(d, −d_выреза)`) или `voxgen sdf <model.vxm>` / `voxgen build --sdf` — дистанционное
  преобразование бинарного объёма (точный EDT + лёгкое размытие 3³ у поверхности) для любой модели.
- Нет поля — мешер работает по бинарной маске как раньше (Laplacian surface nets); поле есть —
  Hermite-путь автоматически (`voxgen render --styles smooth|mix`, подпись «nets hermite»).

**Порт в voxbody (C++, пока не реализовано):** `VoxelVolume` получает опциональный `PackedByteArray sdf`
(int8, та же раскладка; пустой массив = поля нет). Операции среза обязаны его обновлять: для вырезаемой
формы с расстоянием `d_shape` (отрицательным внутри формы, в тех же 1/16 вокселя) новое значение
`sdf = max(sdf, −d_shape)` (вычитание SDF: «минимум» из расстояний до двух новых поверхностей со
знаком), для добавления — `sdf = min(sdf, d_shape)`; после операции восстановить согласованность
(твёрдое → `≤ −1`, воздух → `≥ 0`). Мешер при наличии поля ставит вершины в ноль-пересечения, без — как сейчас.

## Экспорт в `.vox` (MagicaVoxel)

voxgen дополнительно пишет `.vox` (формат 150, с `nTRN`/`nSHP` на каждую часть) для просмотра и ручной правки в MagicaVoxel. Там хранится только цвет; при обратном импорте (`voxgen import-vox`) материал восстанавливается по таблице «цвет палитры → материал», которую voxgen кладёт рядом в `<name>.vox.json`.
