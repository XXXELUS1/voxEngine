# voxEngine Lab — проект Godot 4.7

Лаборатория для воксельных голов: открыть, покрутить, побрить, побить, поджечь.
Движок повреждений — GDExtension `voxbody` (`addons/voxbody/`), модели делает `voxgen`.

## Как открыть

1. Собрать расширение (один раз, и после каждой правки C++):
   `cd src/voxbody && scons target=template_debug` → `godot/addons/voxbody/bin/*.so`.
2. Сгенерировать модели (в git их нет):
   `python3 -m voxgen build-all tools/voxgen/specs` → `godot/assets/models/*.vxm`.
   Без них сцена открывается, но в центре экрана висит подсказка «Нет модели…».
3. Открыть папку `godot/` в Godot 4.7 (или `godot --path godot`) и нажать F5.
   Главная сцена — `scenes/lab.tscn`.

## Управление

| Действие | Клавиша / мышь |
|---|---|
| Орбита вокруг головы | ПКМ + движение |
| Зум | колесо мыши |
| Панорама | СКМ + движение |
| Применить инструмент | ЛКМ (удерживать и вести) |
| Бритва / дубина / свеча / ножницы / ложка | 1 / 2 / 3 / 4 / 5 |
| Новая (целая) голова | R |
| Каркас (wireframe) | F |
| Скриншот в `user://screenshots/` (путь печатается в консоль) | F12 |

Инструменты:

- **Бритва** — срез вдоль движения мыши; скорость = глубина (от 0.5 до 4 вокселей).
  Неподвижная бритва не сверлит: режет только при движении мыши. Всё, что отвалилось,
  становится физическим предметом и падает на пол (крошки из одного вокселя исчезают).
- **Дубина** — синяк; уровень 1 по клику, +1 за каждую секунду удержания на месте (до 3).
- **Свеча** — ожог; уровень растёт с временем удержания (0.3 с → 1, 1 с → 2, 2 с → 3).
  Ожог второго уровня сжигает волосы.
- **Ножницы** — стрижка волос до длины 1 воксель вдоль движения.
- **Ложка** — выгрызает сферу (временная замена щипцов/клещей).

HUD (слева сверху): инструмент, имя модели, число вокселей, время последней операции
(операция + отвал + перестройка меша), FPS.

## Проверка без экрана

```
godot --headless --path godot --import                       # один раз: импорт и кэш классов
godot --headless --path godot -s res://tests/run_tests.gd    # тесты расширения; код возврата 1 при провале
xvfb-run -a godot --path godot --rendering-driver opengl3 --resolution 1280x720 \
    -s res://tests/screenshot.gd -- build/lab.png            # скриншот сцены (Compatibility-рендер)
```

## Где что лежит

- `scenes/lab.tscn` — сцена: свет (свеча + холодный контровой), окружение (AgX, SSAO), пол, камера, HUD.
- `scripts/lab.gd` — HUD, R/F/F12; `scripts/tools.gd` — инструменты; `scripts/orbit_camera.gd` — камера;
  `scripts/voxel_debris.gd` — отвалившиеся куски (RigidBody3D).
- `addons/voxbody/voxel.gdshader`, `voxel_material.tres` — шейдер вокселей (шум цвета, AO, блеск крови).
- `tests/` — headless-тесты и скриншот.
- `assets/models/` — сгенерированные `.vxm` (не в git).
